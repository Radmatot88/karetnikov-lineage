## 2. Спецификация Web-to-API эндпоинтов (6 главных баз)

Прямой перехват XHR/JSON эндпоинтов позволяет обходить тяжелый UI и автоматизировать пакетную верификацию 127 слотов предков.

| База / Архив | URL / Web-Интерфейс | Прямой API / XHR Endpoint | Метод | Ключевые параметры запроса | Формат ответа и ценность данных |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Память Народа** (МО РФ) | `pamyat-naroda.ru` | `https://pamyat-naroda.ru/heroes/search-api/` | `GET` | `last_name`, `first_name`, `middle_name`, `date_birth`, `group=all` | JSON: ФИО, точное место рождения (губерния/уезд/село), место призыва, наградные листы с описанием подвига, сканы приказов. |
| **Памяти Героев Великой Войны 1914–1918** (Первая мировая) | `gwar.mil.ru` | `https://gwar.mil.ru/heroes/gt_data/?builder=Heroes` | `GET` | `last_name`, `first_name`, `middle_name`, `birth_place_gubernia`, `page` | JSON: Полные карточки раненых/убитых/пленных, фонд/опись/дело РГВИА, волость и деревня до 1917 года. |
| **ОБД Мемориал** | `obd-memorial.ru` | `https://obd-memorial.ru/html/default.htm` (XHR `/html/search`) | `POST` / `GET` | `f` (фамилия), `n` (имя), `s` (отчество), `y` (год), `entity=000000011111110` | JSON/HTML-таблица: Донесения о безвозвратных потерях, книги погребений, госпитальные книги. |
