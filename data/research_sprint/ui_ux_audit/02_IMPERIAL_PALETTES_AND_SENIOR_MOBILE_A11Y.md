## 1. Клинико-оптический диагноз текущей темы (`#07090e` + `#d4af37`)

В ходе глубокого аудита таблицы стилей `heritage.css` и прототипа интерфейса был зафиксирован критический диссонанс между назначением родового архива и его визуально-эргономическим исполнением.

### 1.1. Оптический феномен галации (Irradiation / Visual Halation) у людей 55–85+ лет
* **Физиология возрастного зрения:** После 50–55 лет в тканях хрусталика глаза накапливаются флуорофоры и нерастворимые белки, снижается прозрачность оптических сред и естественная аккомодация. При чтении со современных смартфонов (экраны Super AMOLED / OLED с абсолютным контрастом каждого субпикселя) светящиеся тонкие белые (`#f1f5f9`) и ядовито-желтые (`#d4af37`) глифы на абсолютно черном поле (`#07090e`) вызывают **эффект галации (светового ореола)**:
  1. Свет от светлых штрихов рассеивается в мутнеющих средах глаза и заливает соседние темные участки сетчатки.
  2. Буквы визуально «плывут», теряют внутренние просветы (особенно в кириллических буквах «е», «в», «б», «о», «а»), контуры штрихов двоятся.
  3. Для распознавания текста пожилой человек вынужден напрягать цилиарную мышцу, что через 2–3 минуты вызывает астенопию (резь в глазах, слезотечение, головную боль).
* **Преимущество светлого пастельного фона (Positive Polarity):** При светлом фоне (`#FAF6EE`) зрачок физиологически сужается (диаметр ~2.5–3 мм против 4.5–5 мм в темноте). Сужение зрачка увеличивает глубину резкости, нивелирует сферические аберрации хрусталика и делает чтение четким даже при начальной возрастной катаракте или пресбиопии.

### 1.2. Семиотический и культурологический провал: «Такси / Криптобиржа» вместо Исторического Архива
* Цветовая связка **«угольно-черный обсидиан + люминесцентное золото»** устойчиво закрепилась в массовом сознании последних 10 лет за двумя паттернами:
  1. Агрегаторы такси и доставки («Яндекс Go Премиум», Uber Black);
  2. Криптовалютные биржи и гемблинг (Binance, Bybit, VIP-казино).
* В контексте многовековой истории рода Каретниковых (мануфактурные фабриканты, купцы 1-й гильдии, ратники XVII века, Пензенская и Оренбургская летописи) подобная гамма выглядит чужеродным «пластиковым неоном». Родовому архиву требуется достоинство государственного архива (РГИА, ГАОО, ЦГАСО), благородство веленевой бумаги, сургучных печатей и железо-галловых чернил.

### 1.3. Катастрофа микрошрифтов в текущем CSS (`heritage.css`)
При инструментальном замере стилей обнаружено **32 селектора** с размером шрифта от `10px` до `11.5px`:
* `font-size: 10px` (строка 611 — бейджи и сноски);
* `font-size: 10.5px` (строки 657, 859, 1218, 1473, 1597, 1642, 1943, 1984);
* `font-size: 11px` (строки 98, 159, 494, 650, 786, 884, 1031, 1100, 1180, 1299, 2056);
* `font-size: 11.5px` (строки 196, 256, 957, 997, 1044, 1209, 1337, 1498, 1617, 1656, 1712, 1858, 1890).
> **Вердикт:** Для родственников 60–85+ лет на экранах с плотностью 400+ ppi шрифт `10–11px` физически эквивалентен печати 4 кеглем в газете. Без лупы прочесть биографию, даты жизни и архивные шифры невозможно.

```javascript
// Легковесный инлайн-скрипт без библиотек (сохранение в localStorage)
(function() {
  const savedScale = localStorage.getItem('karetnikov_font_scale') || 'md';
  document.documentElement.setAttribute('data-font-scale', savedScale);
  
  document.addEventListener('DOMContentLoaded', () => {
    const buttons = document.querySelectorAll('.font-btn');
    buttons.forEach(btn => {
      if (btn.dataset.scale === savedScale) {
        btn.classList.add('active');
        btn.setAttribute('aria-pressed', 'true');
      } else {
        btn.classList.remove('active');
        btn.setAttribute('aria-pressed', 'false');
      }
      
      btn.addEventListener('click', () => {
        const scale = btn.dataset.scale;
        document.documentElement.setAttribute('data-font-scale', scale);
        localStorage.setItem('karetnikov_font_scale', scale);
        buttons.forEach(b => {
          b.classList.toggle('active', b === btn);
          b.setAttribute('aria-pressed', b === btn ? 'true' : 'false');
        });
      });
    });
  });
})();
```

### 3.3. Геронтологическая эргономика касаний (Motor & Tactile Ergonomics)

1. **Минимальная тактильная мишень (`Touch Target Size`):**
   * Все кликабельные элементы (кнопки раскрытия ветвей, переключатели поколений, карточки предков, вкладки, кнопка поиска) имеют **`min-height: 52px`** и **`min-width: 52px`** (требование WCAG 2.2 AAA — не менее 44×44px, геронтологический стандарт проекта — **52px** с учетом возрастного тремора и управления большим пальцем).
2. **Защитные буферные зоны (`Hit-Area Margins`):**
   * Расстояние между соседними интерактивными элементами (например, кнопки перехода между коленами или переключение веток) строго **`≥ 12px`**, исключая случайные промахи и раздражающие ложные срабатывания.
3. **Ликвидация исчезающих браузерных скроллбаров:**
   * На смартфонах узкие нативные полупрозрачные полосы прокрутки путают пожилых пользователей. Контейнеры с горизонтальным скроллом (линейка поколений, фильтры кланов) получают:
     - Крупные боковые стрелки навигации с мягким градиентным затуханием;
     - Плавную фиксацию шага через CSS `scroll-snap-type: x mandatory`;
     - Четкие индикаторы положения (точки пагинации / хлебные крошки).
4. **Тактильный контраст состояний (`Visual Feedback`):**
   * При тапе по карточке предка элемент мгновенно отвечает физическим смещением на `1px` вниз и появлением четкой рамки `2px solid var(--accent-crimson)`, подтверждая родственнику фиксацию нажатия без секундных задержек.
