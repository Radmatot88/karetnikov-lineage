## 1. КРАТКОЕ РЕЗЮМЕ И АРХИТЕКТУРА HTR-ПАЙПЛАЙНА

Для преодоления «барьера 1917 года» и чтения скорописных метрических книг XVIII–XIX вв. в проекте развернут специализированный инструментарий:
1. **Генератор поисковых масок:** создает запросы с учетом дореволюционной грамматики (`ѣ`, `ѳ`, `і`, `ъ`), фонетических мутаций (`о/а`, `б/п`, `х/ш`) и типичных сбоев HTR нейросетей («минимные палочки» скорописи: `п/т/н/и/ш`).
2. **Прямой индекс `ya.ru/archive`:** в базу Яндекса уже загружены оцифрованные фонды **ОГАОО (Оренбург)**, ЦГА Москвы, архивов Астрахани, Нижнего Новгорода и др. Поиск ведется мультимодальной моделью **Alice AI VLM** (2026), которая автоматически связывает графы метрических записей.
3. **Локальный нормализатор (`paleography_ocr_runner.py`):** переводит транскрибированный текст в современную орфографию и автоматически раскрывает метрические и причтенные сокращения (`всприем.` ➔ `восприемники`, `пор.` ➔ `поручители`, `кр-нъ` ➔ `крестьянин`).

## 3. ПАЛЕОГРАФИЧЕСКАЯ МАТРИЦА СКОРОПИСИ И ОБХОД ОШИБОК OCR

В рукописных документах XVIII–XIX вв. (особенно в метрических книгах сельских приходов и ревизских сказках) буквы пишутся беглым слитным почерком. Из-за этого нейросети (как Яндекс VLM, так и Tesseract/Kraken) регулярно путают визуально похожие графемы.

### Таблица типичных графических смешений скорописи

| Смешиваемая пара | Причина в скорописи | Пример в наших фамилиях / селах | Что искать в `ya.ru/archive` |
| :--- | :--- | :--- | :--- |
| **п / т / н / и / ш** | Минимное письмо (одинаковые вертикальные палочки без отрыва пера) | `Каретников` ➔ `Каретииков`, `Кареттиков`, `Карепников`<br>`Куманин` ➔ `Кумании`, `Куматин` | `Каретииков`, `Карепников`, `Кумании` |
| **к / н / п** | Выносная ножка `к` сливается с соседней буквой | `Каретников` ➔ `Наретников`, `Паретников` | `Наретников Плешаново` |
| **а / о** | Аканье писцов и ненажатая петля буквы `о` | `Каретников` ➔ `Коретников`<br>`Романов` ➔ `Раманов` | `Коретниковъ`, `Рамановъ` |

| **ѳ / ф / т / о** | Внутренняя волна фиты `ѳ` сливается с овалом или перекладиной `т` | `Ѳедоръ` ➔ `Федор`, `Тедор`, `Оедор` | `Ѳедоръ`, `Тедоръ` |

  1. Открыть нужное дело в `ya.ru/archive`.

## 6. СЛОВАРЬ СОКРАЩЕНИЙ МЕТРИЧЕСКИХ КНИГ И РЕВИЗСКИХ СКАЗОК

При чтении архивных записей скрипт `paleography_ocr_runner.py` автоматически преобразует сокращения по следующему стандарту:

| Сокращение в источнике | Раскрытое значение | Роль в генеалогическом древе |
| :--- | :--- | :--- |
| **всприем. / воспріем. / воспр.** | **восприемники** | Крестные родители (часто родные братья, сестры или дедушки/бабушки младенца) |
| **пор. / поручит. / поруч.** | **поручители** | Свидетели на венчании (родственники жениха и невесты по их отцовским ветвям) |
| **кр-нъ / кр-нинъ / кр.** | **крестьянин** | Сословие прямого предка |
| **кр-ка / кр-нка** | **крестьянка** | Мать или крестная |
| **каз. кр.** | **казенный крестьянин** | Государственный крестьянин (ревизии в Казенной палате) |
| **пом. кр.** | **помещичий крестьянин** | Крепостной (искать фонд помещика в ГАОО/ГАПО) |
| **одн. / однодв.** | **однодворец** | Потомок служилых людей засечных черт XVII века |
| **сол. / солдат.** | **солдат** | Рекрут или отставной солдат царской армии |
| **свящ. / священ.** | **священник** | Совершавший таинство иерей |
| **діак. / диак.** | **диакон** | Член причта |
| **псал. / псаломщ.** | **псаломщик** | Автор каллиграфической записи в метрике |
| **бракосоч.** | **бракосочетались** | Ссылка на Часть II метрической книги |
| **род. / родивш.** | **родился** | Ссылка на Часть I метрической книги |
| **пом. / умерш. / погреб.** | **умер / погребен** | Ссылка на Часть III метрической книги (причина смерти) |
| **рев. сказк. / рев.** | **ревизская сказка** | Подушная перепись податного населения (1719–1858 гг.) |
